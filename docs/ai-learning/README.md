# AI Learning Plan for Intelligent Document Management

This folder captures the developer and architect learning notes for adding AI capabilities to the Django Document Management platform.

## Goal

Evolve the application from a traditional document repository into an AI-powered knowledge platform using open-source and cloud AI services.

## Current Project Context

The application currently includes:

- Django backend
- PostgreSQL backend target
- OCR extraction
- Okta OIDC authentication
- OpenShift CRC deployment
- Ollama running inside OpenShift
- Cloudflare Tunnel access
- Planned pgvector semantic search
- Planned RAG assistant

## Recommended Implementation Order

1. PostgreSQL + pgvector
2. Embedding provider abstraction
3. Document embedding table/model
4. Re-embedding management command
5. Kubernetes/OpenShift Job for re-embedding
6. Semantic search UI/API
7. RAG assistant
8. AI metadata extraction
9. Provider switching between Bedrock, Gemini, and local Ollama

## Key Architecture Principle

Embeddings must be generated and queried using the same embedding model/provider. If the embedding provider changes, existing document embeddings should be regenerated or stored in a separate embedding namespace/table keyed by provider and model name.
